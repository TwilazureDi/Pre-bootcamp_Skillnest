## Practical Activities
The practical activities carried out focused on the basic use of Visual Studio, Github and Python. 

### Github
Proof of this is the creation of this repository and its management through the actions: commit, pull and push.

### Visual Studio
Configuring the IDE to read and execute .py files via command-line interface and installing extensions.

[VS_Practicas](https://github.com/TwilazureDi/Pre-bootcamp_Skillnest/tree/main/VS_Practicas)

### Python 
The fundamentals of Python were tested through practice-oriented exercises:
- Basic syntax
- Conditionals
- Loops
- Functions
  
As well as the fundamentals of object-oriented programming (OOP):
- Classes
- Inheritance
- Modules
- Method Overriding
- Polymorphism

[Python_Practicas](https://github.com/TwilazureDi/Pre-bootcamp_Skillnest/tree/main/Python_Practicas)
